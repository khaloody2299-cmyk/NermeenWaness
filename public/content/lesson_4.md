# الدرس الرابع: المعاملات البرمجية، الجمل الشرطية واتخاذ القرار

## المعاملات الحسابية (Arithmetic Operators)
تستخدم للقيام بالعمليات الرياضية الأساسية على القيم الرقمية أو المتغيرات:
1. **الجمع (`+`):** ` $total = $num1 + $num2; `
2. **الطرح (`-`):** ` $diff = $num1 - $num2; `
3. **الضرب (`*`):** ` $prod = $num1 * $num2; `
4. **القسمة (`/`):** ` $quot = $num1 / $num2; `
5. **باقي القسمة (`%`):** ` $rem = $num1 % 2; ` (يستخدم بكثرة لمعرفة الرقم الزوجي من الفردي).

## معاملات المقارنة (Comparison Operators)
تستخدم لمقارنة قيمتين ببعضهما، وتُرجع دائماً قيمة منطقية (`true` أو `false`).
1. **التساوي (`==`):** يتحقق من تساوي القيمتين فقط.
2. **التطابق التام (`===`):** يتحقق من تساوي القيمتين وتطابق نوع البيانات (Data Type) معاً.
3. **عدم التساوي (`!=` أو `<>`):** يتحقق من اختلاف القيمتين.
4. **أكبر من وأصغر من (`>`, `<`, `>=`, `<=`):** للتحقق من النطاقات الرقمية وتخطي حد معين.

## المعاملات المنطقية (Logical Operators)
تُستخدم لربط شرطين أو أكثر معاً في جملة واحدة:
1. **و (AND أو `&&`):** يجب تحقق جميع الشروط معاً.
2. **أو (OR أو `||`):** يكفي تحقق شرط واحد على الأقل.

## آليات التحكم واتخاذ القرار
تُعد هياكل اتخاذ القرار الركيزة الأساسية للتحكم في التدفق المنطقي للبرنامج، فبدلاً من التنفيذ الخطي المتتابع، تسمح هذه الهياكل باختيار المسار المناسب استناداً إلى البيانات المدخلة.

### 1. الجملة الشرطية البسيطة (`if` statement)
تقوم بتنفيذ كتلة من الأكواد إذا وفقط إذا كان الشرط صحيحاً (true).
```php
<?php
$grade_score = 100;
if ($grade_score === 100) {
    echo "درجة كاملة!";
}
?>
```

### 2. الجملة الشرطية المزدوجة (`if...else` statement)
تُوفر مساراً بديلاً في حال عدم تحقق الشرط المنطقي الأول.
```php
<?php
$grade = 45;
if ($grade >= 50) {
    echo "النتيجة: ناجح";
} else {
    echo "النتيجة: راسب";
}
?>
```

### 3. البنية الشرطية المتعددة (`if...elseif...else`)
تُستخدم عندما يكون لدينا خيارات متعددة ومتتالية، حيث يقوم البرنامج بفحص الشروط واحداً تلو الآخر. بمجرد تحقق شرط، ينفذ كوده ويتجاهل الباقي.
```php
<?php
$grade = 78;
if ($grade < 50) {
    echo "راسب";
} elseif ($grade >= 50 && $grade < 65) {
    echo "مقبول";
} elseif ($grade >= 65 && $grade < 75) {
    echo "جيد";
} elseif ($grade >= 75 && $grade < 85) {
    echo "جيد جداً";
} elseif ($grade >= 85 && $grade <= 100) {
    echo "امتياز";
} else {
    echo "درجة خارج النطاق";
}
?>
```

### 4. جملة الاختيار المتعدد (`switch` statement)
تُعد أسلوباً منظماً لإدارة التدفق البرمجي عندما يعتمد القرار على مطابقة قيمة محددة من بين مجموعة من الخيارات الثابتة (Cases).
```php
<?php
$grade = "B";
switch ($grade) {
    case "A":
        echo "التقدير: امتياز";
        break; // ضروري لمنع تنفيذ الحالات التالية
    case "B":
        echo "التقدير: جيد جداً";
        break;
    case "C":
        echo "التقدير: جيد";
        break;
    default: // الحالة الافتراضية
        echo "رمز التقدير غير معروف";
        break;
}
?>
```

## الشروط المختصرة (Ternary Operator)
تتيح كتابة الشرط (if...else) في سطر واحد مختصر باستخدام المعامل الثلاثي `? :`.
**الصيغة:** `(الشرط) ? (قيمة في حال الصح) : (قيمة في حال الخطأ);`
```php
<?php
$result_msg = ($grade_score >= 50) ? "ناجح" : "راسب";
echo $result_msg;
?>
```
