# الدرس الثامن عشر: دمج تقنيات الذكاء الاصطناعي في بيئة PHP

## 1. تثبيت مكتبة الذكاء الاصطناعي بمدير الحزم (`Composer`)
لدمج الذكاء الاصطناعي وتعلم الآلة في بيئة PHP، نحتاج إلى مكتبات متخصصة مثل **PHP-ML** (PHP Machine Learning). لا يتم دمج هذه المكتبات يدوياً، بل تُدار احترافياً باستخدام مدير حزم PHP الذي يُدعى `Composer`.

```bash
# تثبيت المكتبة داخل المجلد الخاص بالمشروع عبر الطرفية (Terminal)
composer require php-ai/php-ml
```

## 2. استدعاء وتهيئة بيئة التعلم الآلي
يتم استدعاء الحزمة التي تم تنزيلها داخل سكربت PHP باستخدام سطر `require` الأساسي، ليصبح نظام الويب جاهزاً لاستيعاب وبناء الخوارزميات.

```php
<?php
// استدعاء ملف التحميل التلقائي لمكتبات Composer
require_once __DIR__ . '/vendor/autoload.php';

// استدعاء تصنيفات خوارزمية K-Nearest Neighbors (KNN) من مكتبة PHP-ML
use Phpml\Classification\KNearestNeighbors;
?>
```

## 3. هيكلة بيانات التدريب (`Training Data`) والمسميات (`Labels`)
لا يمكن للذكاء الاصطناعي أن يتنبأ بالنتائج من فراغ؛ فهو يحتاج إلى تدريب مسبق. نقوم ببناء مصفوفتين أساسيتين:
- **مصفوفة البيانات (Samples/Data):** تحتوي على الأرقام والمقاييس (مثل درجات الطالب في المواد المختلفة).
- **مصفوفة المسميات (Labels/Targets):** تحتوي على التصنيف النهائي أو النتيجة المقابلة لكل عينة في مصفوفة البيانات (مثل: ناجح، راسب، متفوق).

```php
<?php
// عينات لدرجات 3 مواد: البرمجة، الرياضيات، قواعد البيانات
$samples = [
    [90, 85, 92],  // طالب متفوق
    [40, 35, 45],  // طالب ضعيف
    [70, 75, 68]   // طالب متوسط
];

// المسميات المقابلة لكل عينة
$labels = ['متفوق', 'ضعيف', 'متوسط'];
?>
```

## 4. بناء وتدريب نموذج التصنيف الذكي برمجياً
نقوم ببناء كائن (Object) يمثل الخوارزمية (هنا نستخدم KNN كخوارزمية تصنيف بسيطة وفعالة)، ثم نقوم بتمرير مصفوفات التدريب والمسميات لهذا النموذج ليقوم بـ "التعلم" (Training).

```php
<?php
// 1. بناء النموذج الذكي
$classifier = new KNearestNeighbors();

// 2. تدريب النموذج (Training) استناداً إلى البيانات التاريخية
$classifier->train($samples, $labels);
?>
```

## 5. تنفيذ عملية التنبؤ اللحظي (`Prediction`) للمخرجات التعليمية
بعد أن يتشبع النموذج بالبيانات ويُدرك أنماط التقييم، يُمكننا الآن اختباره بعينة بيانات جديدة تماماً (درجات طالب مستجد لم تُصنف مسبقاً) ونطلب منه التنبؤ بحالة هذا الطالب لحظياً بناءً على ما تعلمه.

```php
<?php
// درجات طالب جديد ليتم تصنيفه
$new_student_marks = [88, 82, 89];

// تنفيذ التنبؤ بناءً على التدريب السابق
$predicted_status = $classifier->predict($new_student_marks);

// عرض النتيجة الذكية للمستخدم
echo "بناءً على الذكاء الاصطناعي، تصنيف هذا الطالب هو: " . $predicted_status;
// النتيجة المتوقعة: متفوق
?>
```
> [!TIP]
> تكمن الأهمية التعليمية لهذا الدمج في إمكانيات غير محدودة لتحليل مستوى الطلاب وتقديم تنبؤات حول أدائهم الأكاديمي بشكل استباقي، ما يُمكّن من توفير تدخلات وتوجيهات تعليمية مخصصة بناءً على المعطيات الضخمة (Big Data).
