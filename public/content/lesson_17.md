# الدرس السابع عشر: الحذف المشروط ومعالجة أخطاء السيرفر

## 1. استخلاص معرّف الحذف الفريد `ID` من الرابط باستخدام `$_GET`
تبدأ عملية الحذف بالتقاط المُعرّف الفريد للسجل المطلوب إزالته تماماً من قاعدة البيانات. يتم إرسال هذا المعرّف عادةً في الرابط عند الضغط على زر أو أيقونة "حذف" بجوار السجل المستهدف.

```php
<?php
// التأكد من وصول المعرف عبر الرابط
if (isset($_GET['delete_id'])) {
    $id_to_delete = $_GET['delete_id'];
}
?>
```

## 2. معالجة المعرّف الرقمي وفلترته لضمان سلامته باستخدام الدالة `filter_var()`
لتأمين النظام ضد محاولات إدخال رموز خبيثة أو نصوص مكان المعرّف الرقمي، يتم استخدام دوال التنقية (Sanitization/Validation) مثل دالة `filter_var()` لضمان أن القيمة القادمة هي عدد صحيح نظيف ومطابق للمعايير.

```php
<?php
// التأكد من أن المعرف عبارة عن رقم صحيح (Integer) وليس حقن SQL
$clean_id = filter_var($id_to_delete, FILTER_SANITIZE_NUMBER_INT);
?>
```

## 3. بناء وتمرير استعلام الحذف المشروط (`DELETE FROM`)
تُعد هذه المهارة الأداة البرمجية المخصصة لتطهير واستبعاد البيانات غير المرغوب فيها من قاعدة البيانات (مثل حذف سجلات الطلاب المنسحبين). يتم بناء الاستعلام باستخدام الأمر `DELETE` ولا بد من إرفاقه بقيد الشرط `WHERE` لاستهداف سجل بعينه.

```php
<?php
// صياغة الاستعلام وحصر التنفيذ على المُعرف المنقى فقط
$delete_query = "DELETE FROM students WHERE student_id = $clean_id";

// تنفيذ الاستعلام
$result = mysqli_query($conn, $delete_query);
?>
```
> [!WARNING]
> تنفيذ أمر `DELETE` دون قيد `WHERE` سيؤدي إلى تدمير محتوى الجدول بأكمله.

## 4. استعراض ومعالجة أخطاء القواعد المحتملة بعملية الحذف
من الضروري إدارة عملية ما بعد التنفيذ لتوجيه المستخدم إلى صفحة النتائج في حالة النجاح، أو إظهار رسالة خطأ تفصيلية تُوضح سبب المنع (مثل وجود قيود مفاتيح أجنبية Foreign Key Constraints تمنع حذف سجل لديه بيانات فرعية). نستخدم دالة التوجيه `header()` للنجاح، و `mysqli_error()` للفشل.

```php
<?php
if ($result) {
    // إذا تمت الإزالة بنجاح، يتم إعادة توجيه المستخدم لصفحة الإدارة
    header("Location: dashboard.php?msg=deleted");
    exit(); // إيقاف تنفيذ أي أكواد لاحقة
} else {
    // طباعة رسالة تفصيلية للمطور أو المستخدم في حالة الرفض من السيرفر
    echo "فشل النظام في حذف هذا السجل بسبب الخطأ التالي: " . mysqli_error($conn);
}
?>
```
