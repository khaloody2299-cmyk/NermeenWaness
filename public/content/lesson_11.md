# الدرس الحادي عشر: تغذية ومعالجة بيانات الجداول (DML - Data Manipulation Language)

## 1. إدراج سجلات وبيانات جديدة داخل حقول الجدول باستخدام الأمر (`INSERT INTO`)
تُعد هذه المهارة الأداة البرمجية التأسيسية لتغذية قواعد البيانات بالمعلومات، حيث يتمثل دورها الوظيفي في إضافة صفوف وسجلات جديدة بالكامل داخل جداول النظام المجهزة مسبقاً.

وتكمن الأهمية التعليمية والعملية لتطبيق أمر الإدراج `INSERT INTO` في كونها الخطوة التنفيذية الأولى لبناء قواعد بيانات حيوية ومتفاعلة (مثل تسجيل بيانات طالب مستجد لأول مرة، أو إضافة مادة دراسية جديدة داخل النظام). وتعتمد آلية عملها على توجيه محرك السيرفر لفتح حزمة سجل جديدة وضخ القيم المدخلة بداخلها، مع التحقق من توافق البيانات مع الأنواع القياسية المحددة للأعمدة لضمان سلامة الهيكل.

### خطوات كتابة أمر إدراج السجلات والبيانات:
1. **استدعاء أداة التغذية البرمجية:** تبدأ الجملة البرمجية بكتابة العبارة المحجوزة `INSERT INTO` بأحرف كبيرة لتنبيه المحرك لبدء عملية حقن البيانات.
2. **تحديد الجدول المستهدف:** ترك مسافة فارغة واحدة، ثم كتابة الاسم الصريح والفعلي للجدول المراد الإضافة بداخل حقوله مثل `students`.
3. **توصيف الحقول المستضيفة:** فتح قوسين هلاليين `()` يكتب بينهما أسماء الأعمدة المراد تعبئتها مع الفصل بين كل عمود والآخر بفاصلة عادية.
4. **استدعاء أداة تمرير القيم:** الانتقال لسطر جديد وكتابة الكلمة المفتاحية `VALUES` بأحرف كبيرة، متبوعة بفتح قوسين هلاليين يكتب بداخلها القيم الفعلية بالترتيب المقابل للأعمدة (مع وضع النصوص بين علامات تنصيص مفردة).
5. **إغلاق جملة الإدراج الهيكلية:** إنهاء السكربت بوضع الفاصلة المنقوطة `;` للإشارة إلى نهاية مسار الأمر الحالي وجاهزيته للتنفيذ الفوري على السيرفر.

```sql
INSERT INTO students (student_name, department) VALUES ('علي أحمد', 'تكنولوجيا التعليم');
```

## 2. صياغة كود إضافة البيانات داخل جميع حقول الجدول بالتوالي (`All columns`)
تُعد هذه المهارة الأسلوب البرمجي السريع والمختصر لعمليات الإدراج الكامل، حيث يتمثل دورها الوظيفي في حقن قيم جديدة داخل كافة أعمدة الجدول دون الحاجة لكتابة أسماء الأعمدة في نص الأمر.
```sql
INSERT INTO students VALUES (1, 'عمر حسن', 'تكنولوجيا التعليم');
```
*يجب مراعاة الترتيب التام لنفس هيكل الجدول لتفادي تداخل البيانات.*

## 3. إدراج البيانات داخل حقول محددة فقط مع إهمال بقية الأعمدة تلقائياً (`Specific columns`)
تُعد هذه المهارة الأداة البرمجية المرنة للتعامل مع البيانات الجزئية أو الاختيارية. يُسند للقيم المهملة القيمة الافتراضية للعمود أو `NULL`.
```sql
INSERT INTO students (student_name) VALUES ('مصطفى رندا');
```

## 4. إدراج عدة سجلات وبيانات مختلفة دفعة واحدة لتقليل طلبات السيرفر (`Multiple Records`)
تُعد هذه المهارة الأسلوب البرمجي الاحترافي لتحسين أداء النظام وضخ البيانات الضخمة (Bulk Insertion)، مما يقلل من عدد الطلبات الموجهة للسيرفر.
```sql
INSERT INTO students (student_name, department)
VALUES 
('أحمد', 'تكنولوجيا'),
('سارة', 'الإدارة'),
('عمر', 'البرمجة');
```

## 5. إدراج بيانات داخل جدول معين بالاعتماد على استخراجها من جدول آخر عبر دمج `INSERT` مع `SELECT`
تُعد هذه المهارة الأداة البرمجية المتقدمة لترحيل ونسخ البيانات بين الجداول (Data Migration).
```sql
INSERT INTO archive_students (student_name, department) 
SELECT student_name, department FROM students WHERE status = 'Graduated';
```

## 6. تحديث قيم البيانات والسجلات الحالية داخل الجدول باستخدام الأمر (`UPDATE`)
تُعد هذه المهارة الأداة البرمجية المخصصة لتعديل وصيانة البيانات المخزنة مسبقاً، وتكمن أهميتها في مواكبة المتغيرات الحيوية داخل النظام (مثل تحديث الدرجات).
```sql
UPDATE students SET department = 'الكلية التكنولوجية';
```

## 7. حذف سجلات مخصصة ومعينة من الجدول باستخدام أمر الحذف (`DELETE`)
تُعد هذه المهارة الأداة البرمجية المخصصة لتطهير واستبعاد البيانات غير المرغوب فيها من قاعدة البيانات بشكل نهائي.
```sql
DELETE FROM students;
```

## 8. توظيف قيد الشرط `WHERE` مع أوامر التحديث والحذف
تُعد هذه المهارة الأداة البرمجية الحارسة والأكثر أهمية لضمان سلامة وأمن قواعد البيانات (Data Security). حيث يتمثل دورها الوظيفي في تقييد وحصر تأثير أوامر التعديل (`UPDATE`) أو المسح (`DELETE`) على سجلات معينة ومستهدفة بذاتها. فبدون هذا القيد يؤدي أي أمر تحديث أو حذف إلى تعديل أو مسح الجدول بأكمله!
```sql
UPDATE students SET department = 'تكنولوجيا التعليم' WHERE student_id = 105;
```
```sql
DELETE FROM students WHERE student_id = 105;
```
