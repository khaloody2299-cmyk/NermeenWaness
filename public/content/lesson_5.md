# الدرس الخامس: حلقات التكرار (Loops)

![التدفق المنطقي](/images/concept_logic.png)

من الأدوات الأساسية التي تتيح تنفيذ أسطر معينة من الكود عدة مرات بناءً على شرط محدد، مما يوفر الوقت والجهد في كتابة الأكواد المتكررة بدلاً من كتابتها آلاف المرات.

## 1. حلقة التكرار المحددة (`for` loop)
تُستخدم لتنفيذ كتلة من الكود لعدد محدد من المرات. يبرز دورها الوظيفي كأداة تضمن تكرار المهام ضمن نطاق عددي ثابت.

**تتكون حلقة `for` من ثلاثة أجزاء رئيسية:**
1. **التهيئة (Initialization):** يتم تعريف العداد بقيمته المبدئية (تنفذ مرة واحدة فقط).
2. **الشرط (Condition):** يتم التحقق منه قبل كل دورة، وإذا كان `false` تتوقف الحلقة.
3. **التحديث (Increment/Decrement):** يتم تنفيذه في نهاية كل دورة لزيادة أو إنقاص العداد.

```php
<?php
// طباعة الأرقام من 1 إلى 5
for ($counter = 1; $counter <= 5; $counter++) {
    echo $counter . "<br>";
}
?>
```

## 2. حلقة التكرار المشروط (`while` loop)
تُصنف كإحدى أدوات "التحقق المسبق". تُستخدم لتنفيذ مجموعة من الأوامر طالما ظل هناك شرط منطقي معين قائماً ومتحققاً. نستخدمها غالباً عندما لا نعرف عدد المرات المحددة مسبقاً، بل نعتمد على استمرارية تحقق الحالة.

```php
<?php
$counter = 1;
while ($counter <= 5) {
    echo $counter . "<br>";
    $counter++; // مهم جداً لمنع التكرار اللانهائي (Infinite Loop)
}
?>
```

## 3. حلقة التكرار اللاحق (`do...while` loop)
تختلف عن سابقتها بأنها تقوم بتنفيذ الأوامر مرة واحدة على الأقل قبل التحقق من الشرط. فإذا كان الشرط خاطئاً من البداية، سيتم التنفيذ لمرة واحدة ثم يتم الخروج من الحلقة.

```php
<?php
$counter = 5;
do {
    echo $counter . "<br>"; 
    $counter--;
} while ($counter >= 1);
?>
```

## 4. حلقة تكرار المصفوفات (`foreach` loop)
أداة تكرار متخصصة ومصممة خصيصاً للتعامل مع "المصفوفات" (Arrays). لا تعتمد على عداد رقمي، بل تعتمد وظيفتها على عدد العناصر الموجودة داخل المصفوفة. مع كل دورة، تقوم بسحب قيمة العنصر الحالي وتضعه في متغير ليتم استخدامه داخل الحلقة.

```php
<?php
$students = array("أحمد", "ياسين", "سارة");

// $students: المصفوفة الأساسية
// $name: متغير يحمل قيمة العنصر الحالي
foreach ($students as $name) {
    echo "اسم الطالب: " . $name . "<br>";
}
?>
```
