# الدرس الحادي والعشرون: تدقيق صحة البيانات (Data Validation)

تُعد سلامة البيانات (Data Integrity) خط الدفاع الأخير للمنصات الرقمية. لا يمكن الاعتماد كلياً على قيود قاعدة البيانات (مثل `NOT NULL` أو `UNIQUE`) أو الواجهة الأمامية. يجب أن نضمن برمجيًا أن محرك (PHP) يفحص ويرفض أي بيانات غير منطقية أو مكتوبة بصيغ غير قياسية.

## 1. تنسيق حالة الحروف باستخدام الدالة `ucwords()`
من المشاكل الشائعة عند توليد التقارير باللغة الإنجليزية ظهور الأسماء بحروف صغيرة (lowercase) مما يفقدها المظهر الرسمي والأكاديمي.
- **وظيفتها:** تقوم بتحويل الحرف الأول من كل كلمة داخل السلسلة النصية إلى حرف كبير (Capital Letter).
```php
<?php
$raw_name = "ahmed mohamed";
$formatted_name = ucwords($raw_name);

echo $formatted_name; 
// النتيجة: Ahmed Mohamed
?>
```

## 2. معالجة قفزات الأسطر في النصوص الممتدة باستخدام دالة `nl2br()`
عندما يكتب المستخدم فقرة طويلة تحتوي على قفزات أسطر (مثل رسالة أو ملاحظات في حقل `<textarea>`)، فإن المتصفح يعرضها كسطر واحد متصل.
- **وظيفتها:** تحويل قفزات الأسطر المخفية (New Lines `\n`) إلى وسوم الـ HTML الرسمية المخصصة للأسطر `<br>` لضمان عرض النص بنفس التنسيق المكتوب.
```php
<?php
$comment = "السطر الأول.\nالسطر الثاني.";
echo nl2br($comment);
/* النتيجة المطبوعة للمتصفح:
السطر الأول.<br>السطر الثاني.
*/
?>
```

## 3. بناء الأنماط النصية القياسية `RegEx` (Regular Expressions)
التعبيرات القياسية هي لغة مصغرة بحد ذاتها، تُستخدم لوضع قوالب (Patterns) صارمة يجب أن يطابقها النص المدخل. مثلاً: "يجب أن يتكون رقم الهاتف من 11 رقماً ويبدأ بـ 01".

```php
<?php
$phone = "01123456789";

// النمط: يجب أن يبدأ بـ 01، يتبعه رقم (0 أو 1 أو 2 أو 5)، ثم 8 أرقام متتالية
$pattern = "/^01[0125][0-9]{8}$/";

if (preg_match($pattern, $phone)) {
    echo "رقم هاتف صالح";
} else {
    echo "صيغة رقم الهاتف خاطئة";
}
?>
```

## 4. تدقيق البريد الإلكتروني والروابط باستخدام الدالة المدمجة `filter_var()`
بدلاً من كتابة تعبيرات قياسية معقدة للبريد الإلكتروني، توفر لغة PHP فلاتر مدمجة جاهزة للتحقق من صحة المدخلات المشهورة.
- **وظيفتها:** تطبيق مرشحات قياسية صارمة لاكتشاف الحسابات الوهمية أو المدخلات الخاطئة في المنظومة.

```php
<?php
$email = "student@university.com";

// نستخدم فلتر التحقق المخصص للبريد الإلكتروني
if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
    echo "بريد إلكتروني موثوق وصحيح التكوين.";
} else {
    echo "خطأ: الرجاء إدخال بريد إلكتروني حقيقي.";
}

// يمكن استخدامه للروابط أيضاً
$website = "https://www.google.com";
if (filter_var($website, FILTER_VALIDATE_URL)) {
    echo "رابط صحيح";
}
?>
```

## 5. توظيف الفحص والتصفية مع المعاملات للتحقق من الحدود الرقمية (Numeric Limits)
في التطبيقات الأكاديمية، لا يكفي التأكد من أن القيمة رقمية فحسب، بل يجب التحقق من أنها تقع ضمن حدود مسموحة (مثل: درجات الطالب يجب ألا تتجاوز 100 ولا تقل عن 0).

```php
<?php
$score = 105;

// فلترة مع تحديد خصائص إضافية (خيارات)
$options = array(
    "options" => array(
        "min_range" => 0,
        "max_range" => 100
    )
);

if (filter_var($score, FILTER_VALIDATE_INT, $options) !== false) {
    echo "الدرجة صالحة ومنطقية.";
} else {
    echo "خطأ: الدرجة خارج الحدود المسموح بها!";
}
?>
```
