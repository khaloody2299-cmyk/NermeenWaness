# الدرس العشرون: معالجة وتنسيق السلاسل النصية (String Manipulation)

تُعد الدوال المتخصصة في التلاعب بالبيانات النصية من أهم الأدوات لتنظيف وتجهيز واجهات النظم التعليمية، حيث يتعامل المبرمج يومياً مع المدخلات والمخرجات بصيغتها اللفظية.

## 1. إزالة المسافات والرموز المخفية باستخدام دالة التنقية `trim()`
يقوم الكثير من المستخدمين بنسخ النصوص ولصقها في الحقول، مما يؤدي غالباً إلى وجود مسافات فارغة غير مرئية أو أسطر إضافية في بداية أو نهاية النص، مما يعيق عملية الفحص أو الترتيب الأبجدي بشكل دقيق.

- **وظيفتها:** اقتصاص الفراغات والرموز العشوائية من الحواف (اليمين واليسار).
```php
<?php
$raw_input = "    أحمد محمد   ";
$clean_input = trim($raw_input);
echo "الاسم النظيف: '" . $clean_input . "'"; 
// النتيجة: 'أحمد محمد'
?>
```

## 2. تفكيك السلاسل النصية الطويلة وتجزئتها إلى مصفوفة باستخدام دالة `explode()`
تخيل وجود نص متصل يحمل عدة علامات أو اهتمامات يفصل بينها رمز محدد (مثل فاصلة `,`). هذه الدالة تقوم بتقسيم هذا النص عند ذلك الرمز وتحول كل جزء إلى عنصر مستقل داخل مصفوفة لسهولة قراءته واستدعائه برمجياً.

- **وظيفتها:** شق السلسلة النصية بناءً على المعامل الفاصل (Separator).
```php
<?php
$skills_string = "برمجة,تصميم,تحليل,شبكات";

// تقسيم النص عند كل (فاصلة)
$skills_array = explode(",", $skills_string);

echo $skills_array[0]; // النتيجة: برمجة
echo $skills_array[2]; // النتيجة: تحليل
?>
```

## 3. تجميع ودمج عناصر المصفوفة وتوليدها كنص متصل باستخدام دالة `implode()`
هي الدالة العكسية تماماً لدالة القطع السابقة. تُستخدم لجمع قائمة من العناصر (المخزنة في مصفوفة) ولصقها بجوار بعضها البعض داخل سلسلة نصية واحدة مفردة، مع وضع رمز فاصل بينها (مثل إضافة علامة `-` بين الأسماء).

- **وظيفتها:** لحم عناصر المصفوفة وتصديرها كـ String.
```php
<?php
$students_array = ["ياسين", "منى", "خالد"];

// ربط العناصر باستخدام (مسافة ثم شرطة ثم مسافة)
$connected_string = implode(" - ", $students_array);

echo $connected_string; 
// النتيجة: ياسين - منى - خالد
?>
```

## 4. معالجة النصوص بإضافة وحذف المائلات العكسية (`addslashes()` و `stripslashes()`)
عند حفظ نصوص تحتوي على علامات تنصيص مفردة (`'`) كالموجودة في الأسماء الأجنبية (مثل `O'Connor`)، قد يظن محرك `SQL` أن هذه العلامة تعني إغلاق الجملة البرمجية ويُصدر خطأً.
- **`addslashes()`**: تضع علامة مائلة خلفية `\` قبل هذه العلامات لتأمينها وتحويلها إلى نص جامد قبل التخزين.
- **`stripslashes()`**: عند استرجاع البيانات وعرضها، نقوم بإزالة العلامات المائلة الزائدة لتعود للقراءة العادية.

```php
<?php
$name_with_quote = "It's an example";

$escaped_name = addslashes($name_with_quote);
echo $escaped_name; // النتيجة: It\'s an example

$original_name = stripslashes($escaped_name);
echo $original_name; // النتيجة: It's an example
?>
```

## 5. حساب طول السلاسل النصية باستخدام دالة `strlen()`
دالة أساسية في التحقق من الشروط القياسية لقواعد البيانات (مثل التأكد من أن كلمة المرور لا تقل عن 8 أحرف لتوفير الحد الأدنى من الأمان، أو أن النص لا يتجاوز سعة الحقل).

- **وظيفتها:** إرجاع عدد الحروف (والفراغات) المكونة للنص.
```php
<?php
$password = "123456";

if (strlen($password) < 8) {
    echo "خطأ: كلمة المرور قصيرة جداً، يجب ألا تقل عن 8 حروف.";
}
?>
```
