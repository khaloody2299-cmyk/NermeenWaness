# الدرس السادس: المصفوفات (Arrays)

تُعد المصفوفات واحدة من أهم بنيات البيانات في لغة PHP؛ حيث تتيح تخزين قيم متعددة داخل متغير واحد. وتتميز المصفوفات بقدرتها العالية على استيعاب أنواع مختلفة من البيانات مثل النصوص، الأرقام وحتى المصفوفات الأخرى.

## 1. المصفوفات المفهرسة (Indexed Arrays)
مجموعة من العناصر يتم تعيين "رقم فهرس" متسلسل لكل عنصر. بشكل تلقائي، يبدأ فهرس العنصر الأول من الرقم (0)، بينما يأخذ العنصر الثاني الفهرس (1).

### كيفية الإنشاء والاستدعاء
يمكن الإنشاء باستخدام الدالة `array()` أو باستخدام الأقواس المربعة المختصرة `[]`.
```php
<?php
// الإنشاء
$subjects = array("برمجة", "تكنولوجيا تعليم", "تصميم");
// أو الصياغة الأحدث:
$subjects = ["برمجة", "تكنولوجيا تعليم", "تصميم"];

// الاستدعاء (طباعة العنصر الأول)
echo $subjects[0]; // سيطبع: برمجة

// إضافة عنصر جديد في نهاية المصفوفة
array_push($subjects, "رسوميات");

// تعديل عنصر موجود
$subjects[2] = "تصميم تعليمي";

// حذف عنصر (لا يعيد ترتيب الفهارس تلقائياً)
unset($subjects[1]); 
?>
```

## 2. المصفوفات الترابطية (Associative Arrays)
في هذا النوع يتم تخصيص اسم أو "مفتاح نصي" (Key) لكل عنصر بدلاً من الاعتماد على الأرقام. وتعتمد هذه المصفوفات على مفهوم "المفاتيح والقيم" (Key-Value Pairs). تُستخدم لتنظيم بيانات معقدة ومرتبطة ببعضها (مثل بيانات الطالب).

### كيفية الإنشاء والاستدعاء
نستخدم عامل الربط السهمي `=>` لربط المفتاح بقيمته.
```php
<?php
$student_profile = [
    "id"    => 202601,
    "name"  => "أحمد محمد محمود",
    "level" => "المستوى الثالث",
    "gpa"   => 3.85
];

// الاستدعاء باستخدام المفتاح النصي
echo "اسم الطالب: " . $student_profile["name"];
?>
```

### استخدام `foreach` مع المصفوفات الترابطية
بما أن المصفوفة الترابطية لا تمتلك أرقاماً متسلسلة، تُعتبر حلقة `foreach` هي الطريقة المثلى لاستخراج مفاتيحها وقيمها.
```php
<?php
foreach ($student_profile as $key => $value) {
    echo "<b>" . $key . ":</b> " . $value . "<br>";
}
?>
```

### دوال هامة للتعامل مع المصفوفات
- **`array_key_exists("key", $array)`**: للتحقق من وجود مفتاح معين قبل استدعائه لتجنب الأخطاء.
- **`array_keys($array)`**: تقوم باستخراج المفاتيح فقط في مصفوفة مفهرسة جديدة.
- **`array_values($array)`**: تعيد ترتيب الفهارس الرقمية للمصفوفة من الصفر.

## 3. المصفوفات متعددة الأبعاد (Multidimensional Arrays)
عبارة عن مصفوفات بداخل مصفوفات أخرى. تستخدم لتنظيم البيانات المعقدة التي تشبه الجداول (صفوف وأعمدة). 

### مصفوفة ثنائية الأبعاد (2D Arrays)
```php
<?php
$marks = [
    "Ahmed" => [
        "Programming" => 95,
        "Operating_Systems" => 85
    ],
    "Khaled" => [
        "Programming" => 78,
        "Operating_Systems" => 98
    ]
];

// الوصول لدرجة أحمد في البرمجة
echo $marks["Ahmed"]["Programming"]; // سيطبع 95
?>
```

### مصفوفة ثلاثية الأبعاد (3D Arrays)
تزداد الأبعاد بزيادة التداخل. وللوصول لعنصر بداخلها سنحتاج إلى 3 مفاتيح أو مؤشرات `[][][]`.
```php
<?php
$college = [
    'Dept_Tech' => [
        'Subjects' => [
            'Programming' => 'Dr. Khaled',
            'Design' => 'Dr. Ahmed'
        ]
    ]
];

// الوصول لاسم الدكتور في قسم التكنولوجيا لمادة البرمجة
echo $college['Dept_Tech']['Subjects']['Programming'];
?>
```
