# الدرس الثالث عشر: إدارة وتأمين الاتصال البرمجي وقواعد البيانات (Database Connections)

![الأمان وحماية الاتصال](/images/concept_security.png)

## 1. فتح اتصالاً برمجياً مع السيرفر (`mysqli_connect()`)
يُعد الاتصال بقاعدة البيانات الخطوة الحيوية الأولى لأي تطبيق ويب تفاعلي. للقيام بذلك في بيئة PHP نستخدم الدالة `mysqli_connect()`. تعتمد الآلية على تمرير المعايير الأربعة الأساسية لربط قاعدة البيانات وحفظ قناة الاتصال في متغير (مثل `$conn`).

### خطوات كتابة كود فتح الاتصال:
```php
<?php
// تمرير المعايير: عنوان الخادم، اسم المستخدم، كلمة المرور، واسم القاعدة المستهدفة
$conn = mysqli_connect('localhost', 'root', '', 'school_db');
?>
```

## 2. فحص حالة ونجاح الاتصال بالسيرفر ومعالجة الأخطاء (`mysqli_connect_error()`)
لضمان عمل النظام بشكل سليم وتجنب انهيار الواجهة عند توقف السيرفر، يجب التحقق من نجاح عملية الاتصال، وفي حالة الفشل، إيقاف التنفيذ وإظهار رسالة خطأ صريحة.

```php
<?php
if (!$conn) {
    die("فشل الاتصال بقاعدة البيانات: " . mysqli_connect_error()); 
}
?>
```

## 3. توظيف الجمل المعدة مسبقاً (`Prepared Statements`) لتأمين البيانات وحظر الاختراق
تُعتبر الجمل المعدة مسبقاً الأسلوب الأهم لتأمين البيانات وحظر هجمات الاختراق وإعادة استخدام خطط التنفيذ داخل السيرفر. تقوم بفصل جملة الاستعلام (SQL) عن البيانات الفعلية المدخلة، مما يمنع ثغرة الـ (SQL Injection) الشهيرة. يتم إرسال هيكل الاستعلام أولاً للسيرفر ليقوم بتجهيزه كقالب ثابت (`Prepare`)، ثم تُرسل البيانات لاحقاً لملء هذا القالب (`Bind`).

### خطوات الكتابة والتوظيف:
1. **تجهيز قالب الاستعلام الهيكلي:** باستخدام علامات استفهام `?` بدلاً من القيم.
2. **التحضير (`mysqli_prepare`):** حفظ الخطة في متغير المعاملة.
3. **الربط والحقن بأمان (`mysqli_stmt_bind_param`):** تحديد نوع البيانات (`"s"` للنصوص، `"i"` للأرقام).
4. **التنفيذ (`mysqli_stmt_execute`).**

```php
<?php
// 1. التجهيز
$query = "INSERT INTO students (student_name) VALUES (?)";

// 2. التحضير
$stmt = mysqli_prepare($conn, $query);

// 3. الربط
$student_name = "نرمين ونيس";
mysqli_stmt_bind_param($stmt, "s", $student_name);

// 4. التنفيذ
mysqli_stmt_execute($stmt);

// إغلاق المعاملة
mysqli_stmt_close($stmt);
?>
```

## 4. تنفيذ أوامر وجمل SQL برمجياً باستخدام الدالة (`mysqli_query()`)
الدالة القياسية لتنفيذ الاستعلامات المباشرة. يتم تمرير رابط الاتصال ومتغير الاستعلام بداخلها.
```php
<?php
$query = "SELECT * FROM students";
$result = mysqli_query($conn, $query);
?>
```

## 5. إغلاق اتصال قاعدة البيانات (`mysqli_close()`)
يُغلق الاتصال فور انتهاء العمليات لضمان كفاءة السيرفر وتوفير موارده. يتم استدعاءها في السطر الأخير في صفحة الأكواد.
```php
<?php
mysqli_close($conn);
?>
```

## 6. استدعاء الإجراءات المخزنة (`Stored Procedures`)
تُنفذ عمليات معالجة البيانات المتكررة مباشرة داخل السيرفر لتسريع النظام.
```php
<?php
$query = "CALL GetTopStudents()";
$result = mysqli_query($conn, $query);
?>
```

## 7. استدعاء الدوال البرمجية (`Stored Functions`)
لإجراء العمليات الحسابية المعقدة وإرجاع قيم محددة للنظام.
```php
<?php
$query = "SELECT CalculateTax(100) AS total_tax";
$result = mysqli_query($conn, $query);
?>
```

## 8. إدارة المعاملات البرمجية المتتالية (`Transaction Concept`)
لضمان سلامة تنفيذ سلسلة من العمليات بالكامل كوحدة واحدة لا تتجزأ أو تراجعها التام عند حدوث خطأ، لمنع تضارب البيانات.
1. **إيقاف التثبيت التلقائي (`mysqli_autocommit`)**
2. **تأكيد التنفيذ للكل عند النجاح (`mysqli_commit`)**
3. **التراجع الشامل عند الفشل (`mysqli_rollback`)**

```php
<?php
mysqli_autocommit($conn, false); // إيقاف التثبيت التلقائي

$query1 = "UPDATE accounts SET balance = balance - 100 WHERE user_id = 1";
$res1 = mysqli_query($conn, $query1);

$query2 = "UPDATE accounts SET balance = balance + 100 WHERE user_id = 2";
$res2 = mysqli_query($conn, $query2);

if ($res1 && $res2) {
    mysqli_commit($conn); // نجاح جميع العمليات
} else {
    mysqli_rollback($conn); // تراجع عن كل شيء عند فشل أي خطوة
}
?>
```
