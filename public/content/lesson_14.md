# الدرس الرابع عشر: الحفظ والمعالجة والتحقق من المدخلات

## 1. فحص صحة المدخلات وضمان تعبئة الحقول الإلزامية في النموذج باستخدام دالتي (`isset()`) و (`empty()`)
تُعد هذه الخطوة الاستباقية لتأمين وتدقيق البيانات أمراً بالغ الأهمية. دورها الوظيفي هو التحقق من أن المستخدم قد ضغط بالفعل على زر الإرسال، وأن الحقول الإلزامية في نموذج الويب تحتوي على بيانات فعلية ولم تُترك فارغة، لمنع السيرفر من معالجة قيم فارغة تؤدي لانهيار الأكواد اللاحقة.

- **`isset()`**: للتأكد من مرور المتغير ووجوده في الذاكرة (مثل ضغط زر الإرسال).
- **`empty()`**: للتحقق من أن حقل الإدخال ليس فارغاً (يتم دمجها مع النفي `!`).

```php
<?php
if (isset($_POST['save_btn']) && !empty($_POST['student_name'])) {
    // كود التجهيز للحفظ هنا
    $user_name = $_POST['student_name'];
} else {
    // التنبيه في حالة عدم الإدخال
    echo "عذراً، يجب ملء حقل اسم الطالب أولاً";
}
?>
```

## 2. معالجة النصوص المدخلة لتأمينها من هجمات الحقن (`SQL Injection`) باستخدام دالة (`mysqli_real_escape_string()`)
تُعد الأداة الوقائية التأسيسية لحماية المواقع. تعمل على تنظيف وتطهير النصوص القادمة من مستخدم الموقع قبل إرسالها لقاعدة البيانات عن طريق إبطال مفعول أي رموز أو علامات تنصيص خاصة (`'` أو `"`) قد تُستغل لتغيير مسار الأوامر البرمجية وتدمير القاعدة. وتقوم بوضع شرطة مائلة خلفية `\` قبل هذه العلامات ليتم اعتبارها كنص عادي وليس كأمر برمجي.

```php
<?php
// تأمين المتغير قبل حقنه
$secure_name = mysqli_real_escape_string($conn, $user_name);

// وضع المتغير المؤمن داخل الاستعلام
$query = "INSERT INTO students (student_name) VALUES ('$secure_name')";
?>
```

## 3. بناء استعلام الإضافة البرمجي (`INSERT INTO`) وتمريره للسيرفر باستخدام دالة (`mysqli_query()`)
بعد التحقق من المدخلات وتنظيفها وتجهيز أمر الحفظ في نص `SQL`، يتم إطلاقه وتمريره للمحرك باستخدام দالة التنفيذ.

```php
<?php
// تمرير الأمر للتنفيذ
$result = mysqli_query($conn, $query);

// فحص نجاح العملية وإعطاء تأكيد للمستخدم
if ($result) {
    echo "تمت عملية التسجيل والحفظ بنجاح!";
} else {
    echo "حدث خطأ أثناء محاولة الحفظ: " . mysqli_error($conn);
}
?>
```

## 4. اختبار منطق البيانات ومطابقتها للمعايير والشروط قبل الحفظ (`Business Logic`)
تطبيق قواعد العمل من خلال إخضاع البيانات لاختبارات السلسلة المنطقية والرياضية بـ `if...else` قبل دمجها. مثال: التحقق من أن الدرجة لا تتجاوز 100 أو تقل عن 0 قبل الإرسال للقاعدة.

```php
<?php
if ($grade_score >= 0 && $grade_score <= 100) {
    // تنفيذ الكود وتخزينه في القاعدة
    echo "الدرجة صالحة سيتم الحفظ...";
} else {
    // رفض الإدخال
    echo "خطأ: يجب أن تكون درجة الطالب بين 0 و 100 فقط.";
}
?>
```
