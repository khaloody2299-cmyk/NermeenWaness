# الدرس الثالث: البنية الأساسية، المتغيرات، أنواع البيانات، ودوال الفحص

![المتغيرات والذاكرة](/images/concept_variables.png)

## قواعد الكتابة الأساسية (Syntax)
يعتمد مفسر لغة PHP على وسوم محددة لتعريف بداية ونهاية الكود البرمجي الخاص باللغة، وهما `<?php` و `?>`. يقوم المفسر بتنفيذ التعليمات التي تقع بين هذين الوسمين فقط، بينما يتجاهل أي محتوى يقع خارجهما، مما يتيح إمكانية دمج أكواد PHP بمرونة داخل ملفات HTML.

**الصيغة العامة:**
```php
<?php
    // كود PHP هنا
?>
```

### قواعد هامة:
1. **نهاية الجمل البرمجية:** كل جملة برمجية في PHP يجب أن تنتهي بفاصلة منقوطة `;`. نسيانها هو أشهر سبب للأخطاء.
2. **المسافات البيضاء:** لغة PHP لا تتأثر بكثرة المسافات أو الأسطر الجديدة.
3. **حالة الأحرف:** الكلمات المحجوزة (مثل `echo, if, while`) لا تتأثر بحالة الأحرف. فكتابة `ECHO` هي نفسها `echo`. لكن أسماء **المتغيرات** حساسة لحالة الأحرف (Case-sensitive).

## التعليقات (Comments)
نصوص تُكتب داخل الكود البرمجي، يتم تجاهلها من قبل المفسر ولا تظهر نتيجتها للمستخدم. تستخدم للتوثيق، الشرح، والتنظيم.

- **تعليق لسطر واحد:** باستخدام `//` أو `#`.
- **تعليقات متعددة الأسطر:** تُحصر بين `/*` في البداية و `*/` في النهاية.

## المتغيرات (Variables)
تُعرف بأنها أماكن محجوزة في ذاكرة الحاسوب تعمل بمثابة 'أوعية تخزينية' لحفظ البيانات ومعالجتها أثناء عمل البرنامج.

**قواعد التسمية:**
1. يجب أن يبدأ المتغير بعلامة الدولار `$`.
2. لا يمكن أن يبدأ برقم. (مثال خطأ: `$1student`).
3. لا يمكن استخدام الرموز الخاصة، ويُسمح فقط بالشرطة السفلية `_` (Underscore).
4. أسماء المتغيرات حساسة لحالة الأحرف (`$age` مختلف عن `$Age`).

```php
<?php
    $student_name = "أحمد";
    $student_age = 20;
?>
```

## أنواع البيانات (Data Types)
لغة PHP "مرنة النوع"، أي يستنتج المفسر النوع تلقائياً بناءً على القيمة المسندة:
1. **النصوص (String):** للكلمات والحروف، وتوضع بين علامات تنصيص مفردة `''` أو مزدوجة `""`.
2. **الأرقام الصحيحة (Integer):** مثل `15`.
3. **الأرقام العشرية (Float / Double):** مثل `15.5`.
4. **القيم المنطقية (Boolean):** `true` أو `false`.
5. **المصفوفات (Array):** لتخزين قيم متعددة.
6. **القيم الفارغة (NULL):** تعني غياب البيانات عمداً.

### تحويل الأنواع (Type Casting)
لفرض تحويل نوع البيانات، يوضع النوع المطلوب بين أقواس قبل المتغير:
```php
<?php
    $grade = "95"; // نص
    $grade_int = (int) $grade; // تحويل إلى رقم صحيح
?>
```

## الثوابت (Constants)
أوعية تخزينية لحفظ القيم التي تظل ثابتة طوال فترة تنفيذ البرنامج (مثل الإعدادات والمسارات)، ولا يمكن تغييرها.
تُعرف باستخدام الدالة `define()`:
```php
define("SITE_NAME", "المنصة التعليمية");
echo SITE_NAME; // طباعة الثابت
```

## أوامر الطباعة (Output Commands)
- **`echo`**: أداة أساسية لإخراج النتائج. يمكن استخدامها لطباعة نصوص أو متغيرات، وتدعم وسوم HTML.
```php
echo "<h2>مرحباً بك يا " . $student_name . "</h2>";
```
- **معامل الربط (النقطة `.`)**: يستخدم لدمج النصوص الثابتة مع المتغيرات في سطر واحد.

## دوال الفحص والتحقق
- **`isset()`**: تتحقق من وجود المتغير في الذاكرة وأنه يحمل قيمة (ليس NULL).
- **`empty()`**: تتحقق من خلو المتغير من أي قيمة فعلية (أو إذا كان 0 أو فارغاً).
- **`unset()`**: تقوم بحذف وإلغاء تخصيص المتغير من الذاكرة نهائياً.
