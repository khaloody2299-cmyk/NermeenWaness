# الدرس الخامس عشر: البحث والفلترة وعرض النتائج

## 1. استرجاع كلمات وفئات البحث المرسلة برمجياً باستخدام مصفوفة `$_GET`
تُعد هذه الخطوة التأسيسية لبناء محركات البحث الداخلية. يتمثل دورها في التقاط الكلمات المفتاحية التي كتبها الزائر في خانة البحث وضغط لإرسالها، ليقوم السكربت بسحبها من شريط العنوان وتخزينها في متغيرات مستقلة. وتعتمد الآلية على قراءة المفاتيح الممررة عبر الرابط وتفريغ محتواها النصي فوراً داخل ذاكرة السيرفر.

```php
<?php
// التحقق من أن المستخدم ضغط زر البحث
if (isset($_GET['search_btn'])) {
    // التقاط الكلمة المفتاحية للبحث
    $search_word = $_GET['keyword'];
    
    // التقاط فئة البحث (مثلاً: القسم المختار من قائمة منسدلة)
    $filter_cat = $_GET['category'];
}
?>
```

## 2. معالجة نصوص الاستعلام لتأمينها من الاختراق `SQL Injection`
قبل استخدام بيانات البحث داخل استعلام القاعدة، يجب تأمينها باستخدام `mysqli_real_escape_string()` لمنع المهاجمين من إرسال أوامر خبيثة تعطل النظام.

```php
<?php
$secure_word = mysqli_real_escape_string($conn, $search_word);
?>
```

## 3. بناء استعلام البحث المطور باستخدام معامل المطابقة (`LIKE`)
بدلاً من البحث عن التطابق التام، نستخدم `LIKE` مع الرمز المئوي `%` لجلب النتائج التقريبية والذكية التي تحتوي على الكلمة المطلوبة في أي مكان داخل الحقل النصي.

```php
<?php
// البحث عن أي طالب يحتوي اسمه على كلمة البحث
$query = "SELECT * FROM students WHERE student_name LIKE '%$secure_word%'";
?>
```

## 4. إضافة شروط تصفية ديناميكياً (Advanced Search)
يتمثل دورها الوظيفي في دمج وإضافة شروط تصفية إضافية إلى جملة الاستعلام الأساسية بشكل تدريجي وتلقائي فقط إذا قام المستخدم باختيار فئات محددة. وتعتمد على استخدام معامل الربط النصي `.=` لدمج الشروط المضافة.

```php
<?php
// نبدأ بجملة استعلام أساسية تقبل إضافة الشروط لاحقاً (1=1 هو شرط دائم التحقق لتبسيط الربط)
$query = "SELECT * FROM students WHERE 1=1";

// إذا كانت فئة التصفية ليست فارغة، أضفها كشرط
if (!empty($filter_cat)) {
    // دمج شرط إضافي بالاعتماد على معامل الدمج اللغوي (.=)
    $query .= " AND department = '$filter_cat'";
}

// إضافة شرط البحث النصي بالكلمة
if (!empty($secure_word)) {
    $query .= " AND student_name LIKE '%$secure_word%'";
}

$result = mysqli_query($conn, $query);
?>
```

## 5. عرض السجلات המفلترة ويحدث محتوى الجدول النهائي
بمجرد تنفيذ استعلام البحث، نقوم بتدوير السجلات المسترجعة لعرضها على شاشة المستخدم باستخدام دوال الجلب التكرارية `while`.

```php
<?php
if (mysqli_num_rows($result) > 0) {
    while ($row = mysqli_fetch_assoc($result)) {
        echo "<div class='student-card'>";
        echo "اسم الطالب: " . $row['student_name'] . "<br>";
        echo "القسم: " . $row['department'] . "<br>";
        echo "</div>";
    }
} else {
    echo "لا توجد نتائج مطابقة لبحثك.";
}
?>
```
